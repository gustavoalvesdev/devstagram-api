# API DE SISTEMA TIPO INSTAGRAM

## Clonar o Repositório

```git clone git@github.com:gustavoalvesdev/devstagram-api.git
```

## Instalar as dependências do Composer

```composer install
```

## Importar o script do banco de dados: mvc_psr4.sql

## POST /users/login
- Parâmetros: email, pass
- Senha Padrão: 123456

## POST /users/new
- Parâmetros: name, email, pass

## GET /users/:id
- Parâmetros: jwt
